# 動畫工作台

## 開始使用

雙擊 **啟動本機.command**，瀏覽器會自動開啟動畫工作台。
使用期間保留啟動視窗；結束時按 Control-C。
如果已經啟動，再雙擊只會重新開啟網站。

本機網址：http://127.0.0.1:8766/
首次使用需有 Python 3。本機版本不需要安裝 JavaScript 套件或 build。

## 新增與觀看動畫

1. 左邊選擇動畫，中央即可播放。
2. 按「匯入動畫」加入自己的 sprite 圖片，填入欄數、列數與影格數。
3. 調整速度，或點下方影格查看動作。

目前內建迷你 G-Dragon 舞步與波動拳。匯入功能不會自動生成圖片。

## 換電腦或換網址

先在網頁按「備份」，到新的網頁按「還原」。
自己匯入的動畫存在瀏覽器，不會自動存進這個資料夾；清除瀏覽器網站資料前也要先備份。
內建動畫已包含在 assets，可隨資料夾搬走。

## 之後放到自己的網站

將 **index.html、src、assets** 一起原樣上傳即可，沒有建置步驟。
「啟動本機.command」與這份說明不必上傳。src/serve.py 只是本機啟動器，可不公開。
使用一般靜態網站主機即可；請從網址開啟，不要直接雙擊 index.html。

## 資料夾怎麼看

- **啟動本機.command**：平常只需要開這個。
- **README.md**：使用說明。
- **index.html**：網頁入口。
- **assets/**：動畫圖檔。
- **src/**：程式與樣式，平常不用動。

開發維護：src/app.js 負責介面與播放，src/animations.js 定義內建動畫，src/style.css 控制外觀。使用瀏覽器原生 ESM；修改後重新整理即可。
此儲存庫只包含目前使用的原生 ESM 本機版本，不包含舊版專案或發布壓縮檔。
