# Banner Studio 廣告 Banner 系統

雙擊 **啟動本機.command**，開啟 http://127.0.0.1:8766/ 。需要 Python 3；不需 npm、安裝前端套件或 build。

首頁共七款廣告：荒野槍客，以及緋紅古堡、焰舞傳說、黃金沙域、雷霆神殿、翡翠秘境、落日女俠六款新廣告。
全部固定 600 × 400、3:2、MP4 與動畫 WebP、無聲循環。

## 預設載入模式

上方選擇 iframe / JS、MP4、WebP，頁面會以 ?format=iframe、?format=mp4、?format=webp 重新載入，全部卡片從指定格式開始，可直接分享測試網址。未指定時預設 MP4。素材按可視範圍載入；比較首次網路載入請在開發工具停用快取，並使用相同視窗大小與網路條件。

## 預覽格式比較

卡片下方的 iframe／MP4／WebP 按鈕會直接切換原生預覽，選中格式以金色標示。iframe 載入 JS 動畫嵌入頁、MP4 使用 video、WebP 使用 img；不做格式自動替換。狀態列顯示載入或播放狀態；WebP 圖片載入成功不代表動畫播放相容，仍需肉眼確認是否有動。選好後按「取得此格式廣告」下載或複製嵌入碼。

## 客戶使用

**iframe 嵌入**：選廣告 → 切換 iframe → 按「取得此格式廣告」→ 填活動網址 → 複製嵌入碼 → 貼進網站 HTML 區塊。點擊廣告會另開活動頁。

**MP4 影片**：選廣告 → 切換 MP4 → 按「取得此格式廣告」→ 下載 → 上傳支援影片的後台，設定靜音、循環與活動連結。

**WebP 動畫**：選廣告 → 切換 WebP → 按「取得此格式廣告」→ 下載一個檔案 → 上傳網站後台，並在後台設定活動連結。

首頁預設 MP4；荒野槍客 iframe 已恢復原生 JS 分層播放器（角色六格開槍與五列獨立轉輪），其餘六款 iframe 使用 JS 影格播放器，完全不含 video。另提供 WebP 圖片格式；文案已合成在成品內。更換文案須重新製作動畫，活動連結則可為每位客戶分別設定。
連結設定僅保存在目前瀏覽器；此版本提供廣告素材及嵌入碼，不包含訂單、付款、排期或投放成效後端。

## 正式上線

將 **index.html、embed.html、src/、assets/** 原樣上傳到靜態 HTTPS 主機即可。啟動器及 src/serve.py 不必公開。
從正式網址取得 iframe 嵌入碼。本機 127.0.0.1 網址只能測試，不能提供外部客戶投放。
主機需允許第三方網站嵌入 embed.html（不能設定 X-Frame-Options: DENY/SAMEORIGIN；frame-ancestors 若有設定，需允許客戶網站）。對方編輯器也需接受 iframe。
WebP 上傳後台時須保留所有動畫影格，不可改成 JPG 或靜態縮圖。圖片檔本身不包含活動連結。

## 專案檔案

- index.html：廣告選擇、設定與下載。
- embed.html：供客戶網站嵌入的廣告入口。
- assets/：七個 MP4、七個動畫 WebP 與七張預覽圖。
- src/ads.js：廣告清單、名稱、WebP bytes、mp4Bytes、循環秒數。
- src/app.js、style.css：首頁介面。
- src/embed.js、url.js：嵌入播放與活動連結驗證。
- src/western.js、western.css、assets/western/：荒野槍客原生 JS 播放器與三張分層素材，從舊版 Git 還原。
- src/serve.py：本機啟動器。
- src/素材來源.md：六款新素材的生成 prompt 紀錄。

新增廣告：放入 assets/作品ID.mp4、assets/作品ID.webp 與 assets/作品ID-poster.webp，再在 src/ads.js 加一筆資料，即會同時提供三種投放方式。每款都需檢查動畫確實為 600 × 400、循環播放、清晰且大小適合投放。

舊舞步、波動拳、工作台、舊嵌入元件與測試輸出已從目前專案移除，完整備份位於專案外的 codex-archives/spriteAnimation-before-ad-system-20260909-163320。

## 目前動畫版本

六款新版各有獨立構圖及標題排版：古堡右側錯落標題、火焰斜向橫標、埃及中央對稱、雷神大字、秘境直排、西部電影海報。
每款由12個人物姿勢配合雙向光流過渡，形成88格、24 FPS、3.667秒的往返循環。動作以舉杯、施法、托起寶石、引雷、展示玉飾與扶帽等漸進手勢呈現，避免快速切換大幅度姿勢。荒野槍客保留原動畫。
首頁顯示 MP4 與 WebP 的實際大小，皆維持600 × 400。MP4 使用 H.264、yuv420p、faststart，無音軌。首頁只播放接近可視範圍的影片，支援暫停與減少動態效果偏好。
原始圖集、補間與排版工具、檢查圖均在專案外的 banner-redesign-v3，網站不包含這些製作暫存檔。

## iframe 的 JS 播放

所有 iframe 都不含 video。荒野槍客使用原有分層圖片與 JS 轉輪，其餘六款使用 assets/frames/ 下的三張靜態 WebP 圖集（每張 5 × 3 格），由 src/frame-player.js 以24 FPS切換裁切位置，45格正放後反放成88格循環。這六款是已合成畫面的影格播放，角色、文字與背景並非可獨立操作的圖層。新增同類 JS 廣告時也需提供對應圖集。
